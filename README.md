## 运行项目

1. 使用 HBuilderX 打开本项目。
2. 在 [`pages.json`](pages.json) 中确认需要预览的页面已启用；如需切换启动页，将目标页面移到 `pages` 数组首位。
3. 选择“运行”菜单，将项目运行到浏览器或对应的小程序开发者工具。

各插件的实际兼容范围以插件详情页和对应 `package.json` 中的 `uni_modules.platforms` 配置为准；未标明的平台建议自行验证。

## 目录结构

```text
.
├─ docs/images/plugins/  # DCloud 插件市场示例图
├─ pages/                # 项目级示例页面
├─ static/               # 公共静态资源
├─ uni_modules/          # 插件与模板模块
├─ manifest.json         # uni-app 应用配置
└─ pages.json            # 页面路由配置
```
